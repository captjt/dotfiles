# Global Claude Code Guidance

## Rex inbox

In a Rex pane (REX_SESSION is set), rex-inbox reaches the user and other
agents. Load the rex-inbox skill for how. Reach for it when:

- You need a decision and the user may be away, or they should know
  something later: leave them a note, with what you recommend and what
  you'll do meanwhile.
- You've built something running locally for the user to see or approve:
  share it with rex-inbox, never a localhost link (they may be on their phone).
- A "[rex-inbox] Message #N" arrives: answer it with `rex-inbox reply N`,
  only with substance.
- You finish a task: end with a short summary of what changed, how it was
  checked, and what's left. The inbox shows it on the Finished item.
